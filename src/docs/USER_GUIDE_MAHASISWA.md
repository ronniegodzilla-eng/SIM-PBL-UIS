# Panduan Pengguna (User Guide) - Sistem Informasi PBL
## Peran: Mahasiswa

Dokumen ini berisi panduan penggunaan Sistem Informasi Praktik Belajar Lapangan (PBL) khusus untuk peran **Mahasiswa**.

---

### 1. Registrasi dan Login

#### Registrasi Akun Baru
Jika Anda belum memiliki akun, Anda harus mendaftar terlebih dahulu.
1. Buka halaman utama aplikasi PBL.
2. Klik tombol **Daftar** atau menuju ke [halaman Register](/register).
3. Pilih peran sebagai **Mahasiswa**.
4. Isi form pendaftaran (Nama Lengkap, NIM, Email, dan Password).
5. Klik tombol **Daftar**.

#### Login ke Sistem
1. Buka halaman utama aplikasi PBL.
2. Klik tombol **Masuk** atau menuju ke [halaman Login](/login).
3. Masukkan **Email** dan **Password** yang telah didaftarkan.
4. Klik tombol **Login**.

---

### 2. Dashboard Mahasiswa

Setelah berhasil login, Anda akan diarahkan ke halaman [Dashboard](/dashboard). Di sini Anda dapat melihat ringkasan aktivitas PBL Anda.

**Fitur pada Dashboard:**
*   **Informasi Status PBL:** Status kelompok, dosen pembimbing, dan informasi lokasi PBL.
*   **Pengumuman / Informasi Terbaru:** Informasi dari koordinator atau dosen.
*   **Asisten AI PBL (Chatbot):** Tombol di pojok kanan bawah yang bisa Anda klik untuk bertanya seputar penggunaan sistem atau panduan PBL.

---

### 3. Mengelola Logbook (Buku Harian)

Mahasiswa diwajibkan untuk mengisi logbook sebagai laporan kegiatan rutin PBL.
1. Pada menu navigasi utama, klik menu **[Logbook](/logbook)**.
2. Anda akan melihat daftar logbook yang sudah pernah dibuat.
3. Untuk menambah logbook baru, klik tombol **Tambah Logbook** (atau ikon "+").
4. Isi kelengkapan data: Tanggal, Deskripsi Kegiatan, dan Kendala (jika ada).
5. Klik **Simpan**.
6. Logbook yang sudah disubmit mungkin memerlukan validasi/persetujuan dari Dosen Pembimbing.

---

### 4. Bimbingan Laporan

Menu ini digunakan untuk melakukan bimbingan laporan PBL dengan dosen pembimbing Anda.
1. Pada menu navigasi utama, klik menu **[Bimbingan Laporan](/bimbingan-laporan-mahasiswa)**.
2. Anda dapat melihat riwayat bimbingan atau pesan dari dosen pembimbing.
3. Untuk mengajukan bimbingan baru atau mengunggah draf laporan, klik **Tambah Bimbingan** atau **Kirim Laporan**.
4. Upload file draf laporan Anda dan tambahkan catatan bimbingan.
5. Klik **Kirim**. Pantau halaman ini untuk melihat balasan atau revisi dari Dosen Pembimbing.

---

### 5. Penilaian Teman (Peer Assessment)

Sistem PBL meminta mahasiswa untuk saling menilai kinerja anggota dalam satu kelompok.
1. Pada menu navigasi utama, klik menu **[Penilaian Teman](/penilaian-teman)**.
2. Di halaman ini akan tampil daftar nama teman satu kelompok Anda.
3. Klik tombol **Nilai** pada nama teman yang ingin dinilai.
4. Isi rubrik penilaian yang tersedia sesuai dengan kinerja teman tersebut secara objektif.
5. Klik **Simpan Penilaian**.

---

### 6. Melihat Jadwal Ujian

1. Pada menu navigasi utama, klik menu **[Ujian](/ujian)**.
2. Di halaman ini, Anda dapat melihat informasi mengenai ujian PBL (jadwal, tempat/ruangan, dosen penguji, dan status ujian).
3. Pastikan untuk selalu mengecek menu ini menjelang akhir masa PBL Anda.

## FAQ (Frequently Asked Questions) - Mahasiswa

**Q: Saya lupa password akun saya, apa yang harus dilakukan?**
A: Saat ini Anda dapat melapor kepada Admin/Koordinator PBL untuk meminta reset password akun Anda.

**Q: Bagaimana jika saya salah menginputkan form logbook?**
A: Anda dapat mengedit logbook tersebut selama belum divalidasi/disetujui oleh Dosen Pembimbing. Masuk ke menu Logbook, cari logbook yang salah, dan klik tombol edit (ikon pensil).

**Q: Format file apa saja yang diizinkan untuk diunggah pada Bimbingan Laporan?**
A: Format yang umumnya disarankan adalah PDF atau dokumen Word (.doc, .docx). Pastikan ukuran file tidak melebihi batasan sistem (misalnya maksimal 5MB atau 10MB tergantung kebijakan koordinator).

**Q: Apakah penilaian teman bersifat rahasia?**
A: Ya, nilai yang Anda berikan kepada teman kelompok Anda bersifat rahasia dan hanya akan direkap oleh sistem dan dilihat oleh Dosen/Koordinator berwenang sebagai komponen nilai akhir.

**Q: Asisten AI PBL tidak merespons atau error, apa solusinya?**
A: Pastikan Anda memiliki koneksi internet yang stabil. Jika masih error, Anda bisa memuat ulang (refresh) halaman. Anda juga dapat menghapus riwayat chat dengan mengklik tombol ikon tempat sampah di sudut kanan atas panel chat AI.

**Q: Kapan saya bisa mengajukan ujian PBL?**
A: Silakan berkoordinasi dengan Dosen Pembimbing melalui logbook atau bimbingan laporan. Jika laporan telah disetujui (ACC), jadwal ujian umumnya akan ditetapkan oleh Koordinator/Admin dan akan muncul pada menu Ujian Anda.
